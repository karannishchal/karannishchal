## 🌟 Featured Projects

### 🔐 [Real-Time Fraud Detection System](#) *(in progress)*
End-to-end fraud detection pipeline — from imbalanced-data classification to a deployed FastAPI service with live monitoring. Brings my network security anomaly-detection background directly into an ML deployment context. `Python` `XGBoost` `FastAPI` `MLflow`

### 🏦 [Bank Customer Churn Prediction](https://github.com/karannishchal/bank-customer-churn-prediction)
End-to-end ML pipeline comparing Logistic Regression, Random Forest, and XGBoost. Tuned decision threshold from 0.5 → 0.3 to prioritize recall, reflecting the real business cost of missing at-risk customers. **[🚀 Live App](https://bank-customer-churn-prediction-uv2fyjroluyxf6kestdqyn.streamlit.app/)** `Python` `XGBoost` `Scikit-learn` `Streamlit`

### 🩺 [MSc Dissertation: Label Accuracy vs. Model Architecture](https://github.com/karannishchal/label-accuracy-vs-model-architecture)
Controlled experiment across 4 models (Logistic Regression, Random Forest, XGBoost, MLP) and 2 healthcare datasets (250K+ CDC records), testing how synthetic label noise (20–40%) degrades predictive performance. Found label accuracy consistently mattered more than model architecture — a core Data-Centric AI finding. **[🚀 Live Explorer](https://label-accuracy-vs-model-architecture-f2fwsopq2p3vuak7pk6xdc.streamlit.app/)** `Python` `TensorFlow` `XGBoost` `Scikit-learn` `Streamlit`

### 🔍 [AskMyDocs: Hybrid RAG Search System](https://github.com/karannishchal/askmydocs)
Built sparse (BM25), dense (FAISS + sentence-transformers), and hybrid (Reciprocal Rank Fusion) retrievers from scratch, plus an offline evaluation harness measuring Recall@k and MRR across all three strategies. Generation step grounds answers in retrieved sources with citations, explicitly refusing to answer when context is insufficient. `Python` `FAISS` `BM25` `Sentence-Transformers` `Anthropic API`
